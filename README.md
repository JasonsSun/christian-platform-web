> **English:** A self-hosted, full-stack Christian content & community platform (Simplified Chinese UI).

## 一、项目是什么

一个为中文教会与信徒群体打造的**内容传播 + 社交社区**平台，把日常信仰生活里分散的几件事收拢到一处：

读经、灵修、诗歌、讲道、团契小组、活动报名、代祷、直播 —— 以及支撑这些内容流转的发布、审核、通知与管理后台。

它不是内容聚合站，也不是单一功能的小工具，而是一套**可自主部署、可长期运营**的社区基础设施：任何一间教会、一个团契或一支服侍团队，拿到代码就能在自己的服务器上跑起来，数据完全归属自己。

- **线上实例**：`https://amen.dpdns.org`
- **形态**：Web（响应式 + PWA，可添加到手机桌面）；目前无独立 App

## 三、技术架构

```
浏览器 ──▶ nginx(80/443) ──▶ Next.js 14 App Router(3000) ──▶ MySQL 8(3306)
                                    │
                                    ├── 自研实时总线（WebSocket，ws）
                                    ├── ffmpeg 异步转码 → HLS
                                    └── 存储抽象层 → 本地磁盘 或 S3 兼容对象存储
直播旁路：OBS ──RTMP──▶ MediaMTX ──HLS──▶ 浏览器（hls.js）
```

| 层 | 选型 |
|---|---|
| 前端 | Next.js **14.2.15**（App Router）+ React **18.3.1** + Tailwind CSS |
| 服务端 | 同仓 API Routes + 自研服务层（61 个模块），无 ORM，SQL 全参数化 |
| 数据库 | MySQL 8（62 张表，运行时幂等建表与补列，漏迁移也不会 500） |
| 实时 | WebSocket 自研总线（通知、群聊、直播聊天） |
| 媒体 | ffmpeg 转码 → HLS；MediaMTX 接收 RTMP 推流 |
| 存储 | 本地磁盘 或 S3 兼容（零依赖 AWS Signature V4，不增加镜像体积） |
| 朗读 | Edge TTS（node-edge-tts） |
| 推送 | Web Push + Nodemailer 邮件 |
| 支付 | 微信支付 v3（RSA2048 + AES-GCM）、支付宝 RSA2、Stripe、线下转账 |
| 部署 | Docker Compose（`nginx` + `web` + `db`），单台 VPS 即可 |

**代码位置**：本仓库即唯一可交付实现。历史迭代中另有 Java / NestJS 的平行原型，均不再维护，勿使用。

## 四、部署说明

> 完整步骤见 [`DEPLOY.md`](./DEPLOY.md)，直播专项见 [`LIVE-STABILITY.md`](./LIVE-STABILITY.md)。

### 服务器要求

| 规模 | 建议配置 | 说明 |
|---|---|---|
| 起步（<100 日活） | 2 核 4G，40G SSD | 够跑 Nginx + 应用 + MySQL |
| 含直播/转码 | 4 核 8G 起 | 转码与推流吃 CPU 与带宽 |
| 带宽 | 直播场景按观看人数估算 | 单路 720p 约 2~4 Mbps/观众 |

### 快速部署

```bash
# 1. 一台 Ubuntu 22.04/24.04 或 Debian 12 的 VPS，放行 22/80/443
curl -fsSL https://get.docker.com | sudo sh

# 2. 拉取代码
sudo mkdir -p /opt && cd /opt
git clone <本仓库地址> christian-platform
cd christian-platform

# 3. 配置环境变量
cp deploy/env.example .env
openssl rand -base64 48          # 作为 JWT_SECRET
nano .env                        # 填 DB_PASSWORD 与 JWT_SECRET

# 4. 启动（nginx + web + db 三个容器）
docker compose up -d --build
docker compose logs -f web       # 看到"服务器已就绪"即可，Ctrl+C 退出
```

架构上只有 nginx 对公网开放，应用与数据库都在 Docker 内网，**不要放行 3000/3306**。

### 更新与备份

```bash
# 更新（源码改动必须重建镜像，不能只重启容器）
git pull && docker compose up -d --build web

# 备份：应用内 JSON 快照 + 数据库 SQL 定时备份（见 /admin/backups 与 deploy/backup.sh）
```

### 关键环境变量

| 变量 | 用途 |
|---|---|
| `JWT_SECRET` | 令牌签发密钥，**必填强随机串**（弱密钥会拒绝签发 → 登录 500） |
| `DB_PASSWORD` | MySQL 密码 |
| `STORAGE_PROVIDER` | `local`（默认）或 `s3` |
| `S3_*` | 对象存储的 bucket/region/endpoint/密钥（选 s3 时） |
| `REDIS_URL` | 可选；配置了且装有 ioredis 时限流走 Redis，否则走 MySQL 共享计数（多副本同样生效） |

> 多副本部署时，限流、媒体任务接管、全文索引补齐都已做共享存储与乐观锁处理，不会因多实例而错乱。
